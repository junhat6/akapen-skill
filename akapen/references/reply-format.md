# 【赤ペン回答】固定形 — 3 モード共通の貼り戻し契約

Codexのインライン画面で [送信] を押すと、この形のテキストがfollow-upとして会話に届く。ローカルHTMLでは同じテキストが中継 (`assets/akapen-serve.py`) に保存される。人が会話で「回答しました」と知らせた後、agentは `read` のstdoutで一度だけ読む。
中継が無い時 (`file://` で開いたシート) は [貼り付ける文章を作る] で同じテキストがクリップボードとtextareaに出て、人がエージェントの入力欄へ貼る。どの経路でもagentはこの形だけを読む。

## 形

````text
【赤ペン回答】<label>
赤① (x78% · y30%) <訂正文>
赤② (x12% · y64%) <訂正文>
Q1. <質問>: A — <選択肢> / 補足: <自由記述>
Q2. <質問>: (未選択 = お任せ)
全体への赤ペン: <自由記述 (複数行あり得る)>
## 指摘
#12 [短くする] <ひとこと>
#15 [ここは良い]
## 添削
- 段落 3: 「旧の語」→「新の語」
- 段落 7: (削除)
```markdown
<完成形 Markdown 全文>
```
---
上の回答を反映して作業を続けてください。お任せの項目は推奨案で確定してください。
````

## 規則

- 1 行目 `【赤ペン回答】<label>` と末尾の `---` + 締めの 1 文は **全モード必須・不変** (0.1.0 と互換)
- `赤N (xNN% · yNN%) <訂正文>` — 視覚訂正 (赤ピン)。**ある時だけ**、Q 行より先に並ぶ。座標は提案領域 (`#akSheet`) の左上を原点とする %。座標は「どこの話か」の近似で、**訂正の正は本文**。sheet 内で agent が先打ちする ①②③ (注記) とは別物 — agent は混同しない
- `Qn. <質問>: A — <選択肢> / 補足: <自由記述>` — 標準モードの択一。未選択は `(未選択 = お任せ)`。補足が空なら ` / 補足:` を省く
- `全体への赤ペン:` — 自由記述。次の見出し (`## `) か `---` までが本文
- `## 指摘` — 指摘モードのみ。`#<ブロック番号> [<チップ>] <ひとこと>`。チップだけの行もある。ブロック番号は原稿の DOM 順 (sheet 内で `data-blk` として見える)
- `## 添削` — 添削モードのみ。語単位の差分行を段落ごとに並べ、その後に完成形 Markdown の全文をコードブロックで載せる。表示上折りたたまれても、全文を欠落させない
- 空の節は出さない (指摘 0 件なら `## 指摘` 自体を出さない)
- テンプレを改造するときもこの形を崩さない
